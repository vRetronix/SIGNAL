# SIGNAL
A 90-day creator tracker for streamers and content creators. Track daily and weekly habits, plan your week, keep an Idea Vault and see your stats. Plain HTML, CSS and JavaScript.

## Run
Open `html/index.html` in a browser. No install, no accounts, no backend. Data stays in your browser.

## Structure
```
html/        index.html
CSS/         base.css, mobile.css, desktop.css
Javascript/  app.js
assets/      logos, icons, fonts, images
```
